# TaskFlow Application Screenshots & UI Tour

This directory documents the key views of the TaskFlow enterprise work management platform:

1. **`01_landing_page.png`**: Product showcase landing page with value proposition, interactive architecture breakdown, and demo quick-launch.
2. **`02_executive_dashboard.png`**: Key delivery metrics, status distribution, 7-day velocity net completion, and overdue task indicators.
3. **`03_tasks_table_view.png`**: High information density table with bulk selection toolbar, column filtering, and quick status badges.
4. **`04_kanban_board.png`**: HTML5 drag-and-drop Kanban board across Backlog, Todo, In Progress, Review, and Done swimlanes with optimistic positioning.
5. **`05_calendar_view.png`**: Monthly grid view visualizing task due dates, milestones, and status distribution.
6. **`06_timeline_gantt.png`**: Gantt-style schedule tracking start and target due dates with completion percentages.
7. **`07_task_detail_drawer.png`**: Slide-over drawer with status/priority pickers, subtasks checklist, blocker toggle, discussions feed, and activity timeline.
8. **`08_command_palette.png`**: `Ctrl+K` universal keyboard shortcut with multi-entity fuzzy search across tasks, projects, and users.
9. **`09_my_work.png`**: Dedicated personal hub organized by Overdue, Due Today, Upcoming, and Completed tasks.
10. **`10_projects_page.png`**: Project roster with calculated health indicators (`healthy`, `at_risk`, `delayed`), progress bars, and member rosters.
11. **`11_reports_analytics.png`**: Executive workload distribution, delivery trends, and streaming CSV export.
12. **`12_admin_center.png`**: User management with 1-click role toggles, audit logs with JSON diff inspector modal, and live system health diagnostics.
13. **`13_dark_mode.png`**: Seamless enterprise dark mode with custom CSS custom properties (`data-theme="dark"`).
